GEMINI ARGON — REQUIRED ANALYTICAL DOMAINS
FrostyPickaxe / revised 2026-11-05

Use only actually available tools and evidence. For each domain record source revision/path, observed support, missing evidence, proposed check and escalation. UNKNOWN is preferable to invented capability. The entries below request analytical outputs, not execution.

1. Xenon PPC/VMX128 and AOT: design instruction, endian, floating-point, atomics/fence and indirect-branch coverage audit. Escalate unexplained code/data boundaries, unsupported opcodes or dynamic executable code before declaring static translation viable.
2. XEX/XEXP and STFS: specify exact source/target identity and integrity checks, function/exception-table discovery and update applicability. Distinguish outer package metadata from internal delta requirements. Escalate unresolved source mismatch at G1; never force application.
3. ReXGlue and guest kernel/XAM: compare actual imports and exercised paths to a selected immutable SDK tree, including memory, TLS, exceptions, threads, waits, DPCs, timing, fibers and content APIs. Escalate missing semantics or deadlocks with diagnostics; require reproduction before backports.
4. Xenos and Vulkan: map shader/fetch translation, tiling, textures, render targets, EDRAM, blending, depth, resolves and readbacks. Produce capture-based correctness tests and conditional fallback decisions. Escalate required unsupported behavior at G3; do not infer a LUT bug from a color symptom.
5. Windows/Linux and Intel Gen9 HD 620: design separate driver/API/extension/format/limit surveys and CPU/GPU/memory/thermal measurements. Audit actual SDK feature requirements. Escalate missing faithful fallback or failing measured budgets; API support is not extension proof.
6. SDL3 and guest input: verify selected SDL submodule and XAM bridge semantics for mapping, polling, rumble, focus and hotplug. Specify observable input correctness tests; escalate dropped events, inconsistent guest state or thread races. Do not assume a particular mutex fix.
7. Audio/video/content: inventory actual archives, update overlay, codecs/middleware, streaming, localization and saves. Design sync/underrun, movie, missing-file and save/load checks. Escalate absent required content or unsupported codecs; do not prescribe middleware or callback rates without evidence.
8. Portable C++ and future ARM64/Android: verify selected toolchain, pointer/endian assumptions, host SIMD and memory ordering. Preserve platform interfaces for Bionic/fibers, lifecycle, surfaces, storage and packaging. Escalate x86-only lock-in; Android work remains deferred.
9. Benchmarking, debugging and provenance: define repeatable scenes, frame-time percentiles, CPU/GPU attribution, memory, diagnostics and identity records. Separate cold/warm caches and fidelity changes. Plan local-only inputs/generated derivatives and dependency licensing. Escalate unreviewed redistribution or results without reproducible inputs.
