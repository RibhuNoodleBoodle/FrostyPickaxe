B. NEVER CHEAT BY SUBSTITUTION:
   No existing commercial PC port binaries/assets, no Xenia running the game behind a wrapper, no external streaming, no fake executable, no pre-rendered gameplay, no static screenshot, no fake menu, no empty/hello-world app, no SDL demo, and no fake shader output presented as a game port. C. NEVER CHEAT BY DISABLING CHECKS:
   Do not skip failed tests, modify test expectations to match broken output, suppress assertions, disable validation layers to conceal runtime faults, remove failing test cases, hardcode build success, blanket-ignore exceptions, stub critical imports with unconditional success, or add crash-catching code that masks a nonfunctional path. Diagnostic options may be switched temporarily ONLY when logged as experiments; the final accepted run must use the declared production test configuration. A forced codegen artifact with unresolved critical functions is NOT a passing gate.

D. NEVER CHEAT BY MOVING GOALPOSTS:
   A successful CMake configure is not a compile; a successful SDK test is not a game build; a process lasting 600 seconds is not 600 seconds of gameplay; a splash screen is not boot; Vulkan initialization is not scene rendering; SDL enumeration is not usable controls; third-party GPU output is not Intel HD 620 proof. Never silently reduce game fidelity or delete features needed to pass; if a temporary workaround is used, mark the gate FAILED until genuine behavior is restored.

E. NEVER CHEAT BY STALE RESULTS:
   Record the exact source revision, SDK revision, build directory, binary hash, driver, Vulkan device ID, asset manifest/hash metadata (kept private), launch parameters and test timestamp. Results from another game, another binary, previous branch, or another machine must not be used as current proof. Demonstrate clean/reproducible validation after final code changes.

F. NEVER CHEAT BY FAKE INTERACTION:
   The 10-minute acceptance must show real game state progression using real controller input (physical or independently verifiable host input capture).
